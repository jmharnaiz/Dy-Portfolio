# Niño Victor Portfolio

This is a static portfolio website for Niño Victor Antonio M. Dy.

## Run locally

Open the project folder and start a simple local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy to Vercel

1. Push this project to your GitHub repository.
2. In Vercel, click "Add New Project".
3. Import the repository.
4. Keep the default settings for a static site.
5. Deploy.

Vercel will automatically serve the root `index.html` file.

## Customize

- Update the profile photo in `Dy.jpeg`
- Edit the portfolio content in `index.html`
- Update social links in the footer section of `index.html`
- Adjust theme colors in `portfolio-styles.css`
